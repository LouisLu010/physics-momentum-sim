# Momentum Lab · 动量实验室

一个无需账号和后端的二维物理实验画布，使用 React、Vite 和 Canvas 构建。

在线访问：[Momentum Lab](https://louislu010.github.io/physics-momentum-sim/)。

## GitHub Pages 发布

推送到 `main` 会通过 GitHub Actions 自动运行测试、构建并发布。Pages 的发布来源设置为 **GitHub Actions**。构建从 Pages 配置读取子路径，通过 `BASE_PATH` 传给 Vite；本地开发仍使用根路径。

```sh
BASE_PATH=/physics-momentum-sim/ npm run build
BASE_PATH=/physics-momentum-sim/ npm run preview
```

线上与本地的浏览器保存空间不同，可通过场景 JSON 导出、导入迁移实验。

## 本地运行

```sh
npm install
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址。生产构建运行 `npm run build`，输出在 `dist/`，可托管为静态网站。

## 使用

- 拖入或点击添加弧形槽、滑块、小球、杆、细绳、弹簧和地面。
- 选中元件，在检查器中编辑半径、圆心角、质量、速度、长度等参数。数字按 Enter 或失焦提交，Escape 取消。
- 弧形槽带水平底座，可自由平移、在地面滑动并接受小球的碰撞反作用；质量和初速度均可调整，开启“固定物体”可将其作为静止轨道。
- 拖动小球靠近槽的竖直切点会按球半径对齐到槽内侧；拖动槽底靠近地面会贴平。吸附容差随画布缩放保持一致，按住 Alt 可绕过。吸附仅用于编辑摆放，运行时不锁定物体。
- 连接件的 A、B 两端可接小球或滑块；没有连接物体的端点是固定锚点。也可拖动端点或在画布中点选目标。
- 小球的“杆上滑动”可将其套在杆上，沿杆滑动并受两端限位。
- 地面、重力和接触摩擦可独立关闭。首次开启地面时，如场景没有地面，会添加默认平面。
- “显示轨迹”开关记录小球、滑块的运动路径，可在运行中切换而不暂停。每条路径最多保留 600 个点；关闭、重置或修改场景会清除路径。开关状态会保存，运行轨迹不保存。
- 空格运行 / 暂停；单步前进 1/60 秒；重置恢复本次运行前的自定义场景；Delete / Backspace 删除选中元件。
- 拖动空白区域平移，滚轮或双指缩放；视角复位按钮恢复默认视图。
- 内置弧形槽、动量守恒碰撞、细绳摆球、弹簧滑块和沿杆滑动五种实验。

设计布局自动保存在当前浏览器的 `localStorage`。导出、刷新和重置均使用实验初始状态；模拟过程中的轨迹不持久化。运行后修改参数会暂停，并把当前位置设为新的实验初始状态。JSON 导入最多支持 60 个元件和 1 MB 文件；损坏的保存数据会回退到默认实验。

## 物理模型

以 `100 px = 1 m` 换算 SI 单位，坐标向右、向下为正。主循环固定步长为 `1/120 s`，内部按速度、尺寸及弹簧参数细分子步。

支持质量相关的碰撞冲量、恢复系数、库仑接触摩擦、重力、无质量定长杆、只承受拉力的绳、胡克弹簧与阻尼、沿杆滑动约束。固定支点、地面及固定的弧槽能施加外力，系统动量只有在无合外力时才守恒。底部总动量与总平动动能包含小球、滑块和可动槽体；无摩擦水平地面上的球槽系统保持水平动量守恒。

这是教学用数值模型：滑块与槽体不计算转动；连接件无质量且自身不参与碰撞。滑块与弧槽的接触使用投影支撑半径近似，球与槽为圆形接触。复杂闭合约束及长时间积分会有数值误差。连接件与槽体相连时使用槽的圆心作为连接点，弹簧原长按两连接点间距离计量。

## 验证

```sh
npm test
npm run test:coverage
npx playwright install chromium
npm run test:e2e
npm run build
```

物理单元测试覆盖质量相关碰撞、动量与动能守恒、重力和摩擦、杆绳弹簧约束、导轨反作用、多弧槽和有限地面。浏览器测试覆盖建模、参数编辑、播放与重置、保存与导入导出、桌面及移动布局。

## 结构

- `src/App.jsx`：实验状态、播放、持久化和编辑操作。
- `src/SimulationCanvas.jsx` / `src/canvasDrawing.js`：画布交互、绘制和命中测试。
- `src/Inspector.jsx` / `src/ui.jsx`：属性检查器与通用控件。
- `src/physics.js`：独立可测试的物理引擎。
- `src/model.js`：场景模型、实验示例、导入校验及导轨编辑。
